# Frontend

This directory contains the React + Vite client for the AI Background Remover.

For full setup instructions, architecture notes, API details, and the project roadmap, see the repository [README](../README.md).

```powershell
npm install
npm run dev
```

Available scripts:

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build.
- `npm run lint` checks the React source with Oxlint.
